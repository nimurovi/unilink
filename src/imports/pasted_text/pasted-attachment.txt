==================================================
MODULE — STUDENT DIRECTORY
==================================================

Create a modern Student Directory where students can discover classmates and other students within their university.

The directory should allow students to find people based on:

- Name
- Department
- Program
- Batch
- Section
- Skills
- Interests
- Clubs
- Academic context

The purpose is academic and campus networking.

It should NOT become a social-media platform.

Create NEW Student Portal screens:

1. STUDENT DIRECTORY
2. STUDENT PROFILE
