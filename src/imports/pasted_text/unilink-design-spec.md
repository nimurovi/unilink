# UNILINK — ONE CAMPUS. ONE NETWORK.

Design a premium, modern, animated SaaS web platform called **UniLink**.

UniLink is a digital campus platform that connects university students, teachers, Class Representatives (CRs), clubs, departments, and university administrators in one centralized ecosystem.

The platform brings together:

* Academic information
* Class schedules
* Assignments
* Exams
* Class materials
* Announcements
* Events
* Clubs
* Communities
* Opportunities
* Student profiles
* Campus AI

UniLink should feel like a **real modern SaaS startup product**, not a traditional university management system or ERP.

The visual direction should combine:

**Modern SaaS + Digital Campus + Productivity Platform + Community Platform + Intelligent Technology**

Brand:

**UniLink**

Tagline:

**One Campus. One Network.**

Core message:

**Everything happening on your campus, connected in one place.**

---

Micro interactions:

150–200ms

Normal transitions:

250–400ms

Large section transitions:

500–800ms

Network/decorative animations:

Slow continuous movement.

Use smooth easing curves.

Animations should never make the interface feel slow.
