# UniLink — One Campus. One Network.

Design a premium, modern, highly polished SaaS-style web platform called **UniLink**, a digital campus ecosystem that connects university students, teachers, class representatives (CRs), clubs, departments, and university administrators in one centralized platform.

UniLink is not a traditional university management system and should not look like an old-fashioned ERP, university portal, or generic student dashboard.

The visual direction should feel like a combination of a **premium modern SaaS product, digital campus platform, productivity application, and social community platform**.

Use the following product positioning throughout the design:

**UniLink**
**One Campus. One Network.**

Core message:

**Everything happening on your campus, connected in one place.**

---

## 1. DESIGN PHILOSOPHY

Create a design language that feels:

* Modern
* Premium
* Intelligent
* Clean
* Trustworthy
* Academic
* Connected
* Friendly
* Professional
* Technology-focused
* Human-centered

The interface should feel sophisticated enough to look like a real startup/SaaS product.

Avoid:

* Traditional university portal aesthetics
* Excessive corporate styling
* Old-fashioned ERP layouts
* Overly colorful student-app designs
* Excessive glassmorphism
* Excessive gradients
* Excessive shadows
* Excessive animations
* Cluttered card grids
* Huge decorative illustrations that reduce usability

Use a principle of:

**80% clean SaaS UI + 20% visual effects and motion.**

The design should prioritize usability first and visual impact second.

# 4. TYPOGRAPHY

Use:

**Manrope** for major headings and brand-oriented typography.

Use:

**Inter** for body text, UI labels, navigation, forms, tables, and dashboard content.

Typography should have strong hierarchy.

Hero headline:

Large, bold, confident, approximately 64–80px on desktop.

Section headings:

Approximately 40–52px.

Subheadings:

24–32px.

Body:

16–18px.

Small UI text:

13–14px.

Use generous line-height and whitespace.

Do not make the interface text-heavy.

---

# 5. SPACING & LAYOUT

Use a consistent 8px-based spacing system.

Preferred spacing values:

8 / 12 / 16 / 24 / 32 / 48 / 64 / 80 / 96 / 120

Use large amounts of whitespace.

Desktop content width:

Approximately 1200–1280px.

Hero section should feel spacious and cinematic.

Use asymmetrical layouts where appropriate instead of making every section symmetrical.

---

# 6. CORNER RADIUS

The website should feel alive, but animations must remain professional.

Use:

### Entrance animations

* Fade up
* Fade in
* Slide
* Scale
* Stagger

### Scroll animations

* Text reveal
* Parallax
* Card movement
* Network connections
* Dashboard transitions

### Hover animations

* Slight card lift
* Scale 1.02–1.04
* Soft border highlight
* Icon movement
* Image zoom

### Page transitions

* Smooth fade
* Slight slide
* Shared element transitions where appropriate

### Continuous animations

Only for selected decorative elements:

* Floating network nodes
* Moving connection lines
* AI glow
* Floating dashboard cards

Avoid constant motion on important text or controls.

# 35. IMPORTANT DESIGN RULE

The UniLink landing page must visually communicate the product in the first 5 seconds.

A visitor should immediately understand:

**UniLink connects the entire university experience in one personalized platform.**

The design should look like a **real SaaS startup product**, not a university assignment or generic student management system.

Prioritize:

**clarity → hierarchy → usability → interaction → visual polish**

Create a cohesive, production-quality Figma design system that can later be reused for the authenticated Student, CR, Teacher, Club Admin, Department Admin, University Admin, and Super Admin applications.

Do not design those authenticated dashboards yet. This prompt is specifically for establishing the **UniLink visual language and public SaaS landing page**, which will become the foundation for the next Figma prompts.
